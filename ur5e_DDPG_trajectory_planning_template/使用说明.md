# UR5e DDPG 模型使用说明

## 概述
这个项目使用DDPG（Deep Deterministic Policy Gradient）算法训练UR5e机械臂进行轨迹规划。训练完成后，可以使用训练好的模型进行推理。

## 文件说明

### 训练相关文件
- `ur5e_DDPG_1_3.py` - 主训练程序
- `DDPG.py` - DDPG算法实现
- `ur5e_env.py` - 强化学习环境定义

### 推理相关文件
- `ur5e_inference.py` - 完整的可视化推理程序
- `simple_demo.py` - 简单的模型测试演示
- `使用说明.md` - 本说明文档

## 如何使用训练好的模型

### 方法1：使用简单演示脚本（推荐新手）

```bash
cd /home/zar/Downloads/DDPG_Mujoco-main/ur5e_DDPG_trajectory_planning_template
python simple_demo.py
```

这个脚本会：
- 显示可用的模型文件信息
- 加载最佳模型（按奖励值排序）
- 运行3个测试回合
- 显示每个回合的性能指标

### 方法2：使用完整可视化推理程序

```bash
cd /home/zar/Downloads/DDPG_Mujoco-main/ur5e_DDPG_trajectory_planning_template
python ur5e_inference.py
```

这个脚本会：
- 启动MuJoCo可视化界面
- 加载训练好的模型
- 运行多个回合的推理
- 实时显示机械臂运动

### 方法3：在训练程序中启用模型加载

修改 `ur5e_DDPG_1_3.py` 中的第239行：
```python
load = True  # 改为True
```

然后运行训练程序，它会自动加载之前保存的模型继续训练或进行推理。

## 模型文件说明

训练过程中，模型会保存在 `./expur5e/` 目录下，文件命名格式为：
- `actor{奖励值}_{回合数}.pth` - Actor网络权重
- `critic{奖励值}_{回合数}.pth` - Critic网络权重

例如：
- `actor975_20000.pth` - 奖励值为975，第20000回合的Actor模型
- `critic975_20000.pth` - 对应的Critic模型

## 性能指标说明

- **总奖励 (Total Reward)**: 回合的总奖励值，越高越好
- **步数 (Steps)**: 完成任务的步数，越少越好
- **最终距离 (Final Distance)**: 末端点与目标点的最终距离，越小越好
- **是否到达目标**: 距离小于0.02认为到达目标

## 常见问题

### 1. 模型文件不存在
如果看到"模型路径不存在"的提示，说明还没有训练好的模型。需要先运行训练程序：
```bash
python ur5e_DDPG_1_3.py
```

### 2. 依赖包缺失
确保安装了所有必要的依赖包：
```bash
pip install mujoco torch torchvision numpy scipy matplotlib pandas tensorboardX
```

### 3. 可视化窗口问题
如果可视化窗口无法显示，可以修改 `ur5e_inference.py` 中的 `visualize=False` 来关闭可视化。

### 4. 模型加载失败
检查模型文件是否完整，确保Actor和Critic文件都存在且匹配。

## 自定义使用

### 修改目标点位置
在 `ur5e_env.py` 中修改 `GOAL` 变量：
```python
GOAL = {'x': 0.5, 'y': 0.5, 'z': 0.5}  # 修改为目标位置
```

### 修改推理参数
在推理脚本中修改以下参数：
- `num_episodes`: 推理回合数
- `visualize`: 是否显示可视化
- `model_path`: 模型文件路径

### 添加新的测试场景
可以在推理脚本中添加不同的初始位置和目标位置组合进行测试。

## 训练建议

1. **训练时间**: 建议训练至少10000回合以获得较好的性能
2. **模型保存**: 程序每100回合自动保存一次模型
3. **性能监控**: 观察奖励值的变化趋势，奖励值越高表示性能越好
4. **参数调优**: 可以调整学习率、批次大小等超参数

## 技术支持

2. 依赖包版本

4. 模型文件是否完整
